# こんな頼み方ができます

実在する機能に対応する例だけを載せています。各例は「必要な準備」「実行前の承認」「生成サービスの課金」を分けます。入口の短い一覧は [README.ja.md](../../README.ja.md) です。

コードで裏が取れない依頼（未検証の live 生成の品質、モデルの自動 download、MiniMax への実送信）は載せていません。課金を伴う dry-run も実行していません。

## 30秒の縦型SNS広告の構成案

計画まで。映像の生成は含みません。

> 30秒の縦型SNS広告にしたいです。価値と実績を見せる構成案を出して、計画の確認（Gate 1）で止めてください。生成はまだしないでください。

- **必要な準備：** セットアップ済みの制作案件。短いブリーフ（誰に何を見せるか）。
- **実行前の承認：** `story-guides` → `plan` → `review` は Gate を進めません。`review` は `state.json` を変更しません。この例は計画の確認（Gate 1）で止めます。`run` は別の明示承認が必要です。
- **生成サービスの課金：** この経路では 0。物語構成のカタログは助言であり、実行能力ではありません。

## 手元のセミナー動画を、外部に送らず章分けと要約

手持ち動画のローカル解析です。要約は文字起こしからの抽出であり、生成AIによる言い換えではありません。

> このセミナー動画を外部に送らず、章分けと要約を出してください。モデルは手元のファイルを使い、自動で download しないでください。

- **必要な準備：** 手元の動画。`examples/local-analysis/` を `projects/` へコピー。ローカル Whisper を使う場合は、既存の `.pt` を `model_path` と必須の `model_sha256` に指定する。モデルの自動 download はありません。
- **実行前の承認：** `analyze` は `--actor coordinator` が必要です。フィラー候補は自動削除せず確認待ちです。カットを採用するなら計画の確認（Gate 1）が必要です。
- **生成サービスの課金：** 0。外部 API は使いません。

## 同じキャラで紹介動画を作る

見た目と声を先に文章で固定してから計画します。

> このキャラで商品紹介動画を作りたいです。声・外見・仕草・場所を先に確認してから計画し、計画の確認（Gate 1）で止めてください。

- **必要な準備：** キャラの見た目と声を平易な文で伝えられること。使う生成サービス（adapter）を自分で選ぶこと。未選択の provider CLI・認証・課金は自動導入しません。`character-lock.json` 付き snapshot は Shitate 取り込みなど別経路です。
- **実行前の承認：** 制作 Skill の Identity Lock Protocol を、カット案の前に行います。計画の確認（Gate 1）のあと、Coordinator 承認があるときだけ `run` します。
- **生成サービスの課金：** あり。選んだ生成サービス側のクレジットを使います。

## 前回直した「冒頭0.5秒でBGM」を次も守る

好み・学びの記録です。メモしただけで完成動画は自動修正されません。

> 前回の『冒頭0.5秒以内にBGMを開始する』を、次の計画でも守ってください。

- **必要な準備：** 出力を見たあと。同じ好みには同じ `key`（例: `opening-audio`）を使います。
- **実行前の承認：** 記録そのものはローカルの `feedback.jsonl` へ書きます。テンプレやルールへの反映は、人が昇格を承認したあとの**別作業**です。承認は反映作業の許可であり、prompt / template / rule / Gate / state を自動では変更しません。
- **生成サービスの課金：** 記録は 0。次の生成を実行する場合だけ、その生成の課金が別途かかります。

## Premiere Pro で開いてカットを直す

パイプラインの書き出し（`render`）の代わりではありません。macOS の外部エディタです。

> この制作案件を Premiere で開いて、指定のカットだけ直してください。書き出しと共有はまだしないでください。

- **必要な準備：** macOS、インストール済みの Premiere Pro（有料）、[Premiere接続手順](../premiere-pro.md)。Skill は `$premiere-editing`（Claude Code では `/premiere-editing`）。
- **実行前の承認：** 実編集は Coordinator が対象編集への承認後だけ。MCP の確認トークンは Tsugite の Gate ではありません。案件の Gate は維持します。
- **生成サービスの課金：** Premiere 自体のライセンスが必要です。この経路の MCP に API キーは不要です。生成機能を使わなければ生成クレジットは使いません。
