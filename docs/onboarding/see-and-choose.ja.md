# 何を仕上げたいかで選ぶ

まず手元の短い素材で、完成させたい1本を決めます。継手は、素材・編集内容・確認した版をファイルに残す制作ツールです。見た目が必ず良くなる、普通のAI依頼より速くなる、といった比較結果はまだありません。

## 1. 話している動画から、要点が伝わる短い1本へ

**最初の素材：** 自分が使ってよい短い動画1本。字幕を入れる場合は、確認済みの字幕テキストやSRTも用意します。最初から自動文字起こしや装飾一式を準備する必要はありません。

**目指す完成形：** 使う区間と字幕が決まった15〜30秒のMP4。顔・商品・既存の文字を隠さず、話のタイミングを守ります。

> この動画の要点を15秒で伝えたいです。実際の映像と必要な音を確認し、字幕は渡したSRTの内容から選んでください。まず冒頭3秒を試す計画で止め、確認してから全体に進めたいです。

基本のカット・音・字幕は[既存のローカル編集](../../v2/docs/phase-two.md#sound-captions-and-timing)で扱えます。[Fast Edit](../../v2/docs/phase-two.md#local-analysis-editing-and-reusable-packs)のカードや強調は任意の追加で、別途対応環境と利用条件の確認が必要です。先の18秒デモはその機能見本です。

## 2. 数本の素材から、見せたい順序のある1本へ

**最初の素材：** 使う権利のある2〜3本の短いクリップと、「誰に何を見せたいか」の一文。

**目指す完成形：** 採用する区間と順番が分かる20〜30秒のMP4。最初は生成を加えず、手元の素材だけで組み立てます。

> この3本から、商品の全体→使い方→細部の順に20秒へまとめたいです。素材の実フレームを見て区間を提案してください。追加テロップとBGMは不要です。元ファイルを残し、計画と冒頭プレビューを確認してから進めます。

v2では[区間と順番を明示する編集](../../v2/docs/phase-two.md#sound-captions-and-timing)を使います。既存v1には[複数素材から構成案を選ぶ経路](../multi-source-composition.md)もありますが、v1案件をv2へ自動移行して始めるものではありません。

## 3. 「字幕は控えめ」を次の修正にも引き継ぐ

**最初の素材：** 直したい動画と、その元の素材・設定。「字幕を2か所に」「追加テロップなし」など、今回の希望を伝えます。

**目指す完成形：** 修正内容が設定に残った版と、次の計画へ渡せる好みメモ。

> 前の版は字幕が多かったので、今回は商品名と最後の一言だけにしてください。その希望を好みメモにも残し、変えた字幕区間を計画で見せてください。メモだけで自動修正したことにはせず、実際のプレビューで確認したいです。

好みメモは次の計画の文脈になります。エージェントが実際の設定を直してから再計画し、人が確認します。自然文のメモを保存しただけで、字幕や演出が自動で変わる機能ではありません。

## 普通にAIへ頼む場合と、何が違う？

普通のAIエージェントでも、動画を調べたり編集設定を書いたりできます。継手で増えるのは、編集判断を残し、実行前後の確認へつなぐ共通の置き場所と手順です。

| 確認したいこと | 継手で残るもの | 比較として未検証のこと |
| --- | --- | --- |
| どの素材・区間を使ったか | 素材参照、区間、設定、計画とその内容に結びつく確認 | 通常の依頼より良い場面を選べるか |
| 何を変えたら確認し直すか | 設定や素材が変わると古い計画が使えなくなる検査 | 誤操作を何件減らせるか |
| 「字幕控えめ」を次にも使うか | 好みノートと、次の計画に含まれる文脈 | 継続利用で編集品質や作業時間が改善するか |
| 外部生成を使うときの予算 | サービス別クレジットの台帳と確認 | 実サービスの最終請求との受け入れ確認 |

同じ素材での公平な比較は[比較デモの設計](comparison-plan.ja.md)にまとめています。現時点で削減率や品質の優劣は示しません。

## 素材確認から冒頭試写へつなぐローカル機能

このリポジトリのソース版では、素材のフレーム・音声サンプルを作る → 見た内容と今回の希望を記録する → 3つの方針から選ぶ → 冒頭の別案件を準備する → 通常の確認ページを通して書き出す → 実ファイルを品質レビューする、という入口を追加しています。

[制作ガイドの使い方と対応範囲（英語）](../../v2/docs/production-guidance.md)を参照してください。**alpha.5の配布ファイルにも、この機能を収録しています。** 「素材を生かす」「話の要点」「音と間」は計画用の指針で、映像を見ずに装飾を自動適用する機能ではありません。冒頭プレビューの準備は現在ローカルFFmpeg編集に対応し、他のレンダラーの演出を代わりに再現するとは扱いません。

環境準備は[はじめてガイド](first-video.ja.md)へ。6秒のサンプルは、導入が動くことを確かめてから自分の素材へ進むために使います。

この追加機能のあるリポジトリを開いているなら、エージェントへ次のように頼めます。

> この`tsugite.yaml`案件で制作ガイドを使ってください。まず元のフレームを実際に開き、必要な音を確認し、今回の目的に合う方針を選んでください。追加テロップとBGMは不要です。冒頭3秒の別案件を準備し、確認ページで私の承認を待ってください。書き出し後も実ファイルを見て、まだ見ていない・聴いていない項目は保留で報告してください。

エージェントが扱う入口は、`plugin guide inspect`（素材の証拠を作る）、`select`（観察と方針を保存する）、`preview`（冒頭案件を準備する）、`review`（実出力を検査する）です。`preview`だけでは動画を書き出さず、返された別案件で通常の計画・承認・書き出しを行います。元の全体版の承認を、試写への承認で代用しません。
