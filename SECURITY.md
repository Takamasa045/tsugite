# Security Policy

## Supported versions

Security fixes are made on the latest `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use [private vulnerability reporting](https://github.com/Takamasa045/tsugite/security/advisories/new) for this repository instead.

Include the affected revision, steps to reproduce, the potential impact, and any suggested mitigation. We will acknowledge a valid report and coordinate a fix before public disclosure.
