# kling source

Labs. Implements the documented text generation protocol with synthetic HTTP tests. The formal connection is the Kling CLI while that subscription is already logged in, not an API key written into settings. Support arrives in order, this package does not add a login command, and the real-machine check is open. Offline mode blocks the network entry. Explicit mock mode produces synthetic zero-credit media. Live mode requires an explicitly enabled private connection and a page-approved plan. Keys are read lazily from the chosen environment reference, never written to the project.

Unknown failures/credits hold the reservation; do not infer refunds or automatically repeat submission. Inspect the source package and the connection guide before enabling live mode. A local reservation is not a vendor-enforced remote billing cap.

See the core distribution's docs/connections.md for the dated official references and supported subset. The standalone transport uses no external dependency and accepts an explicitly supplied fetch function, API origin, credentials and trusted download origins.
