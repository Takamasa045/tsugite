# HyperFrames local renderer

Optional labs adapter for an explicitly selected, already installed HyperFrames 0.8.24 CLI, GSAP and Chromium browser. No install, upgrade, auth, browser download, feedback or cloud command is invoked. Telemetry and update checks are disabled through the documented environment overrides. Vendor config/render counters may still be used by the upstream CLI.

A real Mac fixture passed the same plan/page/make/export path with timed captions, looping BGM and SFX. External networking and writes to existing vendor configuration were denied for that test. Runtime, GSAP and browser identity are bound to the plan. Other runtimes/hosts need separate verification. This adapter does not imply vendor endorsement.
