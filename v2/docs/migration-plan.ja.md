# v1からv2への移行判断

この文書は、継手の所有者が「次に何をするか」を決めた記録です。作業者がリポジトリと公開リリースから確認できた事実と、所有者が別途渡した手元の案件数をもとに書いた推奨案を、**所有者は 2026-10-19 にそのまま採用**しました。

## 所有者決定（2026-10-19）

- 下の表の推奨案を、変更せず採用する（Remotion / PixVerse / ElevenLabs は v2で対応。案件専用Remotion構成は v1 に残す。HyperFrames / MiniMax / Editframe / Hypit / Kling / Tesseract は実験枠のまま）。
- **段階2（有料受け入れ、P08 / P10 / B04）はいちばん最後に回す。** いまは課金しない。後で行うときは、いちばんクレジットが少ないサービスから試す。Kling は前払いクレジットが必要な場合がある。
- 段階1・段階3の準備（試用キットと issue 草稿）は、金を使わず進めてよい。確認ページ・予算・秘密情報の扱いを緩くしない。
- 版番号の繰り上げ、npm 公開、`projects/` の変更、有料 API、GitHub issue の作成は、この決定に含まれない。

いまの位置：

- いまの制作の正本は **v1 0.18.0**（`project.yaml` の案件）。
- 試用用の独立配布は **v2 2.0.0-alpha.5**（`tsugite.yaml`）。実課金の受け入れ確認と、第三者3人の初回試用はまだ完了していません。
- 段階2が終わるまで、合成テストを有料受け入れ完了としない。

案件名は書いていません。件数は所有者提供の集計です。

## 5つの段階

段階の番号は要件のまとまりです。実施順は **1 → 3 → 4 → 5 → 2** です。段階2（有料受け入れ）は番号では2番ですが、段階5のあとに回します。段階3の試用と issue 公開は段階2の完了を待ちません。

前の**実施順**の段階が終わる前に、次の段階の「公開」や「課金」を始めません。段階2の課金だけは、段階5のあと、所有者がアカウント・上限・対象サービスを指定してから行います。

| 段階 | やること | 完了とみなす条件 | 所有者の承認 |
| --- | --- | --- | --- |
| 1. コードだけで埋められる差 | 下の表で、所有者が「v2で対応」と選んだ機能のうち、課金や外部アカウントが不要な差を埋める。確認ページ・予算・秘密情報の扱いを緩くしない | 対象の差がテストで確認できる。文書が実装と一致する。有料API・`run` / `render` を使っていない | どの差をこの段階の対象にするかの確認。課金は不要 |
| 2. 有料サービスの受け入れ（最後に実施） | 要件 **P08**（PixVerse / Kling）、**P10**（ElevenLabs）、**B04**（失敗・再実行時のクレジット整合）を、実際の課金単位で確かめる。**段階5のあと、いちばん最後に行う。** 使うサービスはクレジットが最も少ないものから。Kling は前払いクレジットが必要な場合がある | 所有者が選んだ1件ずつの実リクエストで、見積もり・実行・確定（または失敗の保留）が確認ページ経由で記録される。合成テストだけを「受け入れ完了」としない | **必須。** 使うアカウント、上限、対象サービスを所有者が指定するまで始めない。2026-10-19 時点では延期 |

| 5. v1を畳む | 要件 **P15**（実験部品の置き場所）、**S02**〜**S04**（公開後の本数・外部プラグイン・月次更新） | 実験部品の行き先が決まる。v1停止の時期と、残すもの（既存案件の完走など）が文書化される。公開後の目標は「公開してから測る」ものであり、この段階の開始条件ではない | **必須。** v1の停止・移動・外部通知は所有者の明示承認があるまで行わない |

いまのalphaを「正式なv2」や「制作の既定」にはしません。段階4の承認があるまで、既存の `project.yaml` 案件はv1で続けます。

段階3の3人試用は、M06が求める「各フェーズの独立ユーザーゲート」の**いまのalpha分**です。4フェーズ・14週間の全体を段階3で完了扱いしません。段階4へ進む前に、所有者が残りのフェーズゲートをどう扱うかを決めます。

## 採用した方針の読み方

3つの選択肢の意味は次のとおりです。所有者は推奨案どおりにこれを採用しています。

- **v2 で対応**：v2の本番経路として育てる。段階1でコードの差を埋め、有料確認が必要なものは段階2（最後）で確かめる。
- **実験枠（labs）のまま**：v2の既定セットに載せない。必要な人だけが明示して使う。メンテナと実機証拠が揃うまで格上げしない。
- **v1 に残す**：いまのv1案件で完走する。v2へは完成動画のコピーや保管だけを使い、編集グラフは移さない。

段階1の作業範囲は、表で「v2で対応」とした Remotion / PixVerse / ElevenLabs のうち、課金なしで閉じられる差です。

残っている所有者判断（段階3の3人の指名、公開する5件の issue、段階4以降と M06 の残り）は、段階1のコード作業と試用キット準備のあとに決めます。日本語クイックスタート案は alpha.5 で済んでいます。段階3の手順は [試用キット](onboarding/trial-kit.ja.md) と [contribution-backlog](contribution-backlog.md) にあります。
