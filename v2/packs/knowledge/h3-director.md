# H3-style shot direction

Use an intention layer (what the viewer should understand), a shot layer
(subject/action, continuity, camera, place and sound), and an execution layer
(the selected installed plugin's actual supported request). Keep them separate.
Confirm character identity and reference roles before planning related shots.

For each shot, describe one dominant action, the framing, camera motion and its
end state. Explain how the next shot preserves or intentionally changes subject,
screen direction, light and location. Specify narration, music and sound cues
as separate audio timing, not hidden instructions inside a video prompt.

Use a prompt as advice for the selected model, not as a guarantee that it can
follow every instruction. Validate duration, resolution, reference count and
media types against the plugin contract. The guide never selects an account,
spends credits, runs a provider or approves a check.
