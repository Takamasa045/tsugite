# Prompt direction

Describe the subject, action, environment, framing and motion separately. Keep
identity references and scene context consistent across related shots. Explain
the intended visual result in ordinary words, then let the selected plugin
validate its actual model, duration, aspect and reference limits. Never infer
runtime support from a knowledge pack or a model list. Review each source
request and its service-specific maximum before execution.

This is a portable planning guide. It contains no provider invocation, account,
authorization, hidden approval or default paid model selection.
